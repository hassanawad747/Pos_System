Bike Zone POS - SQL-Only LAN Installer

This package supports a local network with ONE database server and MANY POS client computers.
There is no .bak database file in the installer.

Main files:
- App\ = latest compiled Pos_System.exe and DLL files
- Database\000_base_schema.sql = creates a NEW empty POS database schema on a new SERVER
- Migrations\ = all versioned SQL updates (001, 002, 003, ...)
- install_pos_system.bat = main installer entry point
- setup_pos_lan.ps1 = Server/Client setup engine
- Installer.config.json = database/port/install defaults
- VERSION.txt = build commit/date/migration list generated by GitHub Actions

RUN AS ADMINISTRATOR:
  install_pos_system.bat

The installer asks for a role:

1) SERVER
Use this on the manager/server PC that will host the shared database.
The Server option:
- Finds/starts SQL Server or SQL Server Express.
- Enables SQL Mixed Mode authentication.
- Enables TCP/IP on static port 1433.
- Adds a Windows Firewall inbound rule for TCP 1433.
- Asks you to create a Database password.
- Creates database pos_system from Database\000_base_schema.sql when the database does not exist.
- Runs EVERY SQL file in Migrations\ in filename order.
- Creates SQL login bikezone_pos_app using the password you entered.
- If this is a brand-new database, asks for the first POS Admin username/password.
- Installs the desktop application on the server PC too.
- Shows the server computer name and LAN IPv4 address for client setup.

Command shortcut:
  install_pos_system.bat server

2) CLIENT
Use this on cashier/employee PCs connected to the same LAN.
The Client option:
- Does NOT install or create a database.
- Does NOT run CREATE DATABASE.
- Does NOT restore a backup.
- Asks for the SERVER computer name or LAN IP address.
- Asks for the Database password created during Server setup.
- Tests the SQL connection to SERVER:1433 before installing the application.
- Writes App\Database.config automatically.
- Installs the latest desktop application and creates a shortcut.

Command shortcut:
  install_pos_system.bat client

Typical LAN example:
SERVER PC:
  Computer name: MANAGER-PC
  LAN IP: 192.168.1.10
  Database: pos_system
  Port: 1433
  SQL login: bikezone_pos_app

CLIENT PC connection:
  Server: 192.168.1.10
  Database password: same password entered on SERVER

UPDATES:
For a later application update, run the newest installer package on the SERVER first.
- Existing pos_system is preserved.
- 000_base_schema.sql is NOT executed over an existing database.
- All migrations are processed; migrations already recorded in SchemaMigrations are idempotent and do not recreate data.
Then run the same package as CLIENT on each client PC to replace only the desktop application files and keep them pointed at the shared server database.

IMPORTANT:
- Use a stable LAN IP or DHCP reservation for the SERVER PC.
- Do not distribute the database to client computers.
- Do not copy Database.config from one network to another without checking server/IP.
- The database password is stored in Database.config because the current desktop application uses a SQL connection string. Protect the Windows user accounts and installation folder.
- SQL Server Management Studio is NOT required for normal installation; the scripts are executed by PowerShell through System.Data.SqlClient.
