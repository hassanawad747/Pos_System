POS System manual installation steps

Target install folders used by this package:
- Application: C:\BikeZonePOS\App
- Database backup: C:\BikeZonePOS\Database\pos_system.bak
- Database name inside SQL Server: pos_system

Recommended automatic method:
1. Copy this whole installer folder to the other PC.
2. Optional: edit Installer.config.json if you want to change install path, SQL instance, or the connection string.
3. Install SQL Server Database Engine or SQL Server Express.
4. Install sqlcmd if needed.
5. Right click install_pos_system.bat.
6. Choose Run as administrator.
7. Wait until the script finishes and opens the application.

Manual method:
1. Create these folders:
   C:\BikeZonePOS\App
   C:\BikeZonePOS\Database
2. Copy all files from the App folder into C:\BikeZonePOS\App
3. Copy Database\pos_system.bak into C:\BikeZonePOS\Database
4. Make sure SQL Server service MSSQLSERVER or SQLEXPRESS is running
5. Open Command Prompt as Administrator
6. From Command Prompt as Administrator, run this command from the installer folder location:

sqlcmd -S . -E -i "FULL_PATH_TO_THIS_INSTALLER_FOLDER\restore_database.sql"

If your SQL Server is SQLEXPRESS, use:

sqlcmd -S .\SQLEXPRESS -E -i "FULL_PATH_TO_THIS_INSTALLER_FOLDER\restore_database.sql"

7. After restore finishes, run:

C:\BikeZonePOS\App\Pos_System.exe

Important notes:
- For installer-side SQL settings or a custom connection string, edit:
  installer\Installer.config.json
- To change the SQL Server connection on a client PC, edit only this file:
  C:\BikeZonePOS\App\Database.config
- Keep the connection name the same. Change only the connectionString value, for example:
  Data Source=.\SQLEXPRESS;Initial Catalog=pos_system;Integrated Security=True;TrustServerCertificate=True
- If sqlcmd is not found, install Microsoft SQL Server Command Line Utilities.
- If autoDetectSqlInstance is false in Installer.config.json, make sure sqlInstance and sqlServiceName match the target PC.
