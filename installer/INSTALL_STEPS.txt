Bike Zone POS manual installation steps (SQL-only)

Recommended method:
1. Copy the entire installer folder to the target computer.
2. Right-click install_pos_system.bat and choose Run as administrator.
3. Choose SERVER on the manager/database computer or CLIENT on a workstation.
4. Follow the secure password and connection prompts.

SERVER:
- Detects or installs SQL Server Express.
- Creates a new database from Database\000_base_schema.sql only when no database exists.
- Makes and verifies a copy-only backup before upgrading an existing database.
- Runs every Migrations\*.sql file in filename order.
- Preserves existing application data.
- Creates the first POS administrator for a fresh system.
- Installs the Release application and branded desktop shortcut.

CLIENT:
- Requests the SERVER computer name or LAN IP and database password.
- Tests the remote SQL connection before installing.
- Never creates or restores a local business database.
- Installs the Release application and branded desktop shortcut.

This installer intentionally contains no .bak file and has no backup-file dependency.
Operational backups are created and verified on the SERVER by verify_database.ps1.
